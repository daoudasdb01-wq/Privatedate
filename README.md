# AI Images Daily — profil web

Interface responsive inspirée du design de profil montré dans les captures fournies.

## Structure

- `index.html` — structure de la page
- `styles.css` — design responsive
- `script.js` — interactions des boutons et onglets
- `assets/profile.jpg` — photo de profil extraite de la capture fournie

## Lancer

Aucune dépendance n'est nécessaire.

Ouvre simplement `index.html` dans un navigateur.

## GitHub Pages

1. Crée un dépôt GitHub.
2. Ajoute tous les fichiers de ce dossier.
3. Va dans **Settings → Pages**.
4. Sélectionne la branche `main` et le dossier `/root`.
5. GitHub Pages publiera automatiquement le site.


## Image de profil

Le site utilise directement l'image fournie par l'URL Reddit comme photo de profil.
Une image locale `assets/profile.jpg` est conservée comme solution de secours si l'URL externe ne répond pas.
